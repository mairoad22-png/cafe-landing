# ☕ cafe-landing

동네 카페 "모닝브루"를 소개하는 간단한 정적 랜딩 페이지입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (메뉴, 소개, 오시는 길) |
| `style.css` | 스타일 (반응형 레이아웃 포함) |

## 페이지 섹션

- 상단 내비게이션
- 히어로 영역
- 대표 메뉴 카드
- 카페 소개
- 오시는 길
- 푸터

## 사용 방법

별도 설치나 빌드 없이 `index.html`을 브라우저에서 열면 됩니다.

## 참고

카페 이름, 메뉴, 가격, 주소, 전화번호는 예시 내용이므로 실제 정보로 바꿔서 사용하세요.
